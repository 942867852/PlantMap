# PlantMap 植物图谱

基于 Qt 6 Widgets 的 Windows 桌面植物图谱软件，用于按完整分类层级管理植物资料、
照片与检索。数据保存在 JSON 文件中，运行时随程序目录一起携带。

当前版本：**v0.3.2**。完整更新内容见
[RELEASE_NOTES_v0.3.2.md](RELEASE_NOTES_v0.3.2.md)。

## 功能

- 分类树：按 `界 → 门 → 纲 → 目 → 科 → 属 → 种 → 亚种/变种/变型/品种` 层级浏览植物
- 中国地图：展示原生分布省区，点击省份高亮/取消（含港澳台、南海诸岛）
- 图片预览：点击左侧植物，右侧大图与资料即时切换；双击缩略图全屏灯箱翻页
- 只读详情页：集中展示图片、描述、环境需求、生长形态、物候、扩展属性等
- 独立编辑窗口：修改资料、添加/删除别名与照片；支持拖拽/粘贴导入图片
- 快速搜索：支持中文名、拉丁学名、别名、拼音首字母检索
- 高级检索：按生长习性、生命周期、光照、水分、叶型、生长速度、花期月份组合筛选，
  支持保存筛选预设与结果导出 CSV
- 别名管理：每个别名单独保存，支持逐条添加和删除
- 花期显示：连续月份自动合并为区间，如 `2月-4月`、`12月-次年2月`
- 收藏夹：收藏常用植物，快速跳转
- 撤销 / 重做：树与资料编辑均可撤销重做
- 数据库导入：支持导入旧版本数据库并自动迁移；导入前自动备份，
  失败时恢复原数据库，高于当前软件版本的数据库会被拒绝
- 数据导出：把数据库与照片打包导出到任意目录

## 运行

构建完成后，可执行文件输出到项目根目录的 `bin/`，Qt 运行库会在编译时自动部署：

```bash
./bin/PlantMap.exe
```

数据库默认存放在可执行文件同级目录的 `bin/data/`（`plantmap.json` + 照片）。
需要把软件带到另一台电脑时，请复制整个 `bin/` 文件夹而不是单独复制 exe，
否则植物数据不会跟着程序走。

也可以显式指定数据目录：

```bash
./bin/PlantMap.exe --data-dir <数据目录>
```

## 构建

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_PREFIX_PATH=D:/Qt/6.10.1/mingw_64 \
  -DCMAKE_CXX_COMPILER=D:/Qt/Tools/mingw1310_64/bin/g++.exe
cmake --build build
```

## 自检

```bash
./bin/plantmap_selftest.exe
```

自检覆盖：分类链逐级插入、拉丁学名全局查重、节点删除、JSON 往返一致性。

## 目录结构

```
src/core/        数据模型（纯 QtCore，无界面依赖）
src/ui/          Qt Widgets 界面（主窗口、只读详情、编辑页）
tests/           命令行自检
docs/            架构说明
bin/             编译产物 + Qt 运行库 + 运行时数据（不进入 git）
```

详细设计见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。
