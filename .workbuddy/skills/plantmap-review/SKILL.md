# PlantMap 全代码审查

范围：`src/core`、`src/ui`、`tests/selftest.cpp`、CMakeLists.txt，必要时对照 `docs/ARCHITECTURE.md`。

默认只审查并输出结论；用户要求修复时才改代码；未经指示不做 git/发布操作。输出格式：问题(严重度) + 文件:行 + 证据 + 建议；未经验证的疑点要标注“待确认”。

## 分类树与搜索

- 层级只能逐级添加（界→…→亚种），禁止跳级/倒挂；亚种是末级；同一父节点下名称唯一。
- 资料只能挂在“种/亚种”；删除子树会级联清理资料、照片引用与拉丁名索引。
- 拉丁学名规范化后全库唯一；节点编辑/改名后索引仍一致。
- 三个搜索框（中文名/别名/拉丁学名）：只有输入匹配文本才出现候选；空输入或输入 `,`、`/` 不得弹出全部植物；候选须能命中亚种中文名。
- 别名按独立条目逐条匹配与增删，不存在把整串别名当作一个条目的路径。
- 高级检索为各条件 AND 精确筛选；未填条件不参与；没有对应属性的节点不误命中。
- 搜索激活时禁止针对当前树节点的增删改；搜索结束后树恢复正常且无“幽灵”节点。
- 左侧树：宽度可用分隔条随意调整；默认只展开到“目”；种/亚种名称完整显示，不用省略号截断。

## 显示格式

- 只读详情页中尺寸范围、株高、冠幅等属性各占一行，不挤在同一行。
- 月份区间：连续合并（2,3,4 → `2月-4月`）、跨年（12,1,2 → `12月-次年2月`）、找不到连续段起点（典型为全选）→ `全年` 或 `1月-12月`。
- 数值范围：只有低端 → `最低 xx`；只有高端 → `最高 xx`；两端均无 → 不显示该项。
- 编辑页“范围填反”校验必须先排除未填端（哨兵值），再比较大小：温度哨兵 -100、
  湿度/pH/耐寒区/尺寸哨兵 0。漏掉哨兵判断会把“只填低值”误判为填反（2026-09
  曾在温度/湿度/pH 上发现此回归，耐寒区与尺寸的写法是正确范本）。
- 数值（尤其 pH）：落库与展示统一 1 位小数；double 比较先按 0.1 精度舍入，杜绝浮点误差导致的伪“未保存”。
- 新植物编辑页不预填有效默认值。

## 编辑与交互

- 未保存检测基于真实差异；关闭编辑页时无修改直接关闭，有修改才提示。
- 取消编辑要回滚全部操作，包括删除刚添加的照片；失败时不残留数据与文件。
- 添加照片失败时清理已复制的文件；照片目录没有孤儿文件。
- 照片操作采用延迟提交：添加/移除只改表单列表、不写文档；“保存”时统一
  setInfo，并按会话快照（m_photosAtSessionStart）清理被移除引用且全库无人
  再引用的历史照片；“取消”时删除会话复制的文件（2026-09 起的设计，此前
  照片操作立即写文档，会绕过表单未保存内容并残留孤儿文件）。
- 范围“填反”校验必须先排除未填端哨兵（温度 -100、湿度 0、pH 0.0），
  单边填写（如“最低 15 ℃”）是合法输入，与显示层单边显示一致。
- 编辑页与高级检索的所有下拉/数值控件屏蔽鼠标滚轮误改，包括展开后的弹出列表。
- 导入流程先备份，失败恢复原数据库；高于当前 schema 的导入被拒绝。
- 导入前的 saveData() 必须检查返回值：保存失败要中止导入，否则备份的是磁盘上
  的旧文件，导入成功后内存未保存数据被静默覆盖（2026-09 发现此处忽略了返回值）。
- 导入失败还原后要与成功路径一样重置 UI 状态（清空搜索框/缩略图缓存）；
  samePhotosDir（导入当前目录文件）时还原跳过照片目录的删除再拷回。
- 图片解码一律走 PhotoImageUtils::loadScaled 系列（缩略图/搜索图标/大图预览），
  禁止为 88px 缩略图全量解码原始大图。
- fromJson 对数值字段做范围钳制（与编辑控件量程一致），防止越界值在编辑页
  被 spinbox 二次钳制后造成假性“未保存修改”。

## 持久化与迁移

- `schema_version` 与 `DbVersion::kCurrentSchemaVersion` 一致；迁移链只追加，历史迁移函数不得被改写。
- `loadFromFile` 先迁移再解析；迁移后数据与直接保存新版一致（自检覆盖）。
- 默认数据目录为 exe 同级 `bin/data/`，支持 `--data-dir`；代码无写死的源码绝对路径。
- JSON 往返无损；旧字段缺失时有安全默认值。

## 验证手段

- 静态：用 `rg -n` 查找 double 直接 `==`、未接滚轮过滤器的下拉控件、月份/范围格式化逻辑、toJson 与 fromJson 字段不配对、硬编码路径等。
- 动态：

```powershell
$env:Path='D:\Qt\Tools\mingw1310_64\bin;D:\Qt\Tools\Ninja;D:\Qt\Tools\CMake_64\bin;'+$env:Path
cmake --build build\Desktop_Qt_6_10_1_MinGW_64_bit-Debug --target PlantMap plantmap_selftest
bin\plantmap_selftest.exe
```

- 需要 GUI 验证时，请用户配合操作，或仅在用户明确同意后运行程序；不自动点击界面按钮。
