# PlantMap 全代码审查

范围：`src/core`、`src/ui`、`tests/selftest.cpp`、CMakeLists.txt，必要时对照 `docs/ARCHITECTURE.md`。

默认只审查并输出结论；用户要求修复时才改代码；未经指示不做 git/发布操作。输出格式：问题(严重度) + 文件:行 + 证据 + 建议；未经验证的疑点要标注“待确认”。

## 分类树与搜索

- 层级只能逐级添加（界→门→纲→目→科→属→种），禁止跳级/倒挂；同一父节点下名称唯一。
- 种之下并列挂“亚种/变种/变型/品种”四个同级末级（末级不能再分）；`nextLower(种)` 默认
  返回“亚种”，新增变种/变型/品种走 `addNode(parentId, name, rank)` 显式等级重载。
- 资料只能挂在“种 / 亚种 / 变种 / 变型 / 品种”；删除子树会级联清理资料、照片引用与拉丁名索引。
- 拉丁学名规范化后全库唯一；节点编辑/改名后索引仍一致。
- 搜索（中文名/别名/拉丁学名 + 拼音首字母）：只有输入匹配文本才出现候选；空输入或输入
  `,`、`/` 不得弹出全部植物；候选须能命中亚种/变种/变型/品种中文名；拼音首字母走
  `Pinyin::matchesInitials`（输入 `yx` 匹配“银杏”）。
- 别名按独立条目逐条匹配与增删，不存在把整串别名当作一个条目的路径。
- 高级检索为各条件 AND 精确筛选；未填条件不参与；没有对应属性的节点不误命中。
- 搜索激活时禁止针对当前树节点的增删改；搜索结束后树恢复正常且无“幽灵”节点。
- 左侧树：宽度可用分隔条随意调整；默认只展开到“目”；种/亚种名称完整显示，不用省略号截断。
- 复制节点（cloneSelected）：副本拉丁学名自动加后缀避免与原件冲突；副本子树层级合法。
- 树导航“展开全部/折叠全部”按钮行为正确，不残留错误的展开状态。

## 显示格式

- 只读详情页中尺寸范围、株高、冠幅等属性各占一行，不挤在同一行。
- 月份区间：连续合并（2,3,4 → `2月-4月`）、跨年（12,1,2 → `12月-次年2月`）、找不到连续段起点（典型为全选）→ `全年` 或 `1月-12月`。
- 数值范围：只有低端 → `最低 xx`；只有高端 → `最高 xx`；两端均无 → 不显示该项。
- 编辑页“范围填反”校验必须先排除未填端（哨兵值），再比较大小：温度哨兵 -100、
  湿度/pH/耐寒区/尺寸哨兵 0。漏掉哨兵判断会把“只填低值”误判为填反（2026-09
  曾在温度/湿度/pH 上发现此回归，耐寒区与尺寸的写法是正确范本）。
- 数值（尤其 pH）：落库与展示统一 1 位小数；double 比较先按 0.1 精度舍入，杜绝浮点误差导致的伪“未保存”。
- 新植物编辑页不预填有效默认值。

## 编辑与交互

- 未保存检测基于真实差异；关闭编辑页时无修改直接关闭，有修改才提示。
- 取消编辑要回滚全部操作，包括删除刚添加的照片；失败时不残留数据与文件。
- 添加照片失败时清理已复制的文件；照片目录没有孤儿文件。
- 照片操作采用延迟提交：添加/移除只改表单列表、不写文档；“保存”时统一
  setInfo，并按会话快照（m_photosAtSessionStart）清理被移除引用且全库无人
  再引用的历史照片；“取消”时删除会话复制的文件（2026-09 起的设计，此前
  照片操作立即写文档，会绕过表单未保存内容并残留孤儿文件）。
- 范围“填反”校验必须先排除未填端哨兵（温度 -100、湿度 0、pH 0.0），
  单边填写（如“最低 15 ℃”）是合法输入，与显示层单边显示一致。
- 编辑页与高级检索的所有下拉/数值控件屏蔽鼠标滚轮误改，包括展开后的弹出列表。
- 导入流程先备份，失败恢复原数据库；高于当前 schema 的导入被拒绝。
- 导入前的 saveData() 必须检查返回值：保存失败要中止导入，否则备份的是磁盘上
  的旧文件，导入成功后内存未保存数据被静默覆盖（2026-09 发现此处忽略了返回值）。
- 导入失败还原后要与成功路径一样重置 UI 状态（清空搜索框/缩略图缓存）；
  samePhotosDir（导入当前目录文件）时还原跳过照片目录的删除再拷回。
- 图片解码一律走 PhotoImageUtils::loadScaled 系列（缩略图/搜索图标/大图预览），
  禁止为 88px 缩略图全量解码原始大图。
- fromJson 对数值字段做范围钳制（与编辑控件量程一致），防止越界值在编辑页
  被 spinbox 二次钳制后造成假性“未保存修改”。
- 图片拖拽 / 剪贴板粘贴导入（dragEnterEvent / dropEvent / keyPressEvent）：
  文件路径校验后走与文件对话框共用的 `addPhotosFromFiles`，不能绕过照片安全校验。
- 草稿自动保存：编辑窗口误关后下次打开能恢复上次输入；保存成功/取消关闭后草稿文件
  必须清除，不能残留过期草稿。

## 地图可视化（合规重点）

- 省界数据含港澳台、南海诸岛及十段线；台湾是中国不可分割的一部分，省名用“台湾省”。
- 地图按固定经纬度纵横比绘制，窗口缩放时等比缩放不变形（不纵向/横向拉伸）。
- 省名标注用省轮廓质心定位 + 字号自适应，小区域（海南/台湾/北京等）也能看清、不重叠错位。
- 点击省份高亮/取消多选，选中集合与 `SpeciesInfo::nativeRegions`（adcode 列表）一致。
- 只读详情页地图不可编辑；编辑页地图可编辑。合规：正式发布须以自然资源部标准地图为准并标注审图号。

## 撤销重做与收藏夹

- 撤销/重做（UndoCommand 四种类型 AddNode/RemoveNode/RenameNode/SetInfo + 双栈）：
  - 删除节点的撤销要能恢复子树 JSON 与被删照片文件字节；
  - Add/Remove 会重建节点、id 可能变化，undo/redo 后要更新命令里的 nodeId；
  - 栈深有上限（如 100），超限丢最旧；undo/redo 后栈状态一致、动作按钮 enable 状态正确；
  - **undo/redo 后要同步 UI 状态**：rebuildTree 用 QSignalBlocker 不会触发选择信号，
    必须显式 `rebuildTree(newId)` 选中节点 + `showNode(newId)` + 同步收藏/对比按钮
    （setFavorite/setCompared）+ refreshActionState，否则树无选中、工具栏按钮被禁用
    （2026-09 发现 undo/redo 后收藏/对比状态停留在旧节点）。
- 收藏夹：收藏状态持久化（load/save），切换收藏即时更新按钮外观与详情页；收藏夹窗口
  能正确跳转到对应植物。

## 批量操作与物种对比

- 批量操作（batchDelete / batchSetAttribute）基于树 ExtendedSelection 多选：
  - 批量删除要先去重父子节点（只删“最上层”），逐节点入 undo 栈；
  - **批量设置属性按钮文案与实际应用数必须一致**：setInfo 强制学名非空，没有资料
    （hasInfo=false，尚无学名）的节点无法 setInfo，必须预先过滤并在提示中说明
    “跳过 N 个无资料节点”，不得出现“应用到 N 个”实际只改部分的误导（2026-09 发现）。
- 物种对比（compareList 会话列表 + CompareDialog）：
  - 详情页“＋ 加入对比”按钮（checkable）与主窗口 m_compareList 双向同步；
    从搜索/收藏夹跳转、undo/redo、删除节点后都要刷新按钮状态；
  - 删除节点（removeSubtreeAndPhotos）要同步清理对比列表中该子树所有 id
    （删除前收集 doomedIds，删除后 removeAll）；
  - 对比对话框内移除植物按**节点 id** 删除（不能按列下标——列表可能含已被过滤的
    无效节点导致下标错位删错）；删空后要显示空状态而非空表格（2026-09 发现下标 bug）。

## 异步任务生命周期

- 凡 QtConcurrent::run / QThread 后台任务捕获 `this`：
  - 模态编辑窗可在任务进行中被关闭（对象销毁），回调若在已销毁对象上执行会崩溃；
  - `QMetaObject::invokeMethod(context, functor, QueuedConnection)` 的 context 销毁后
    functor 会被 Qt 丢弃（不会崩），但要处理“孤儿文件/资源”：
    后台已复制但回调未执行的文件需用 QPointer 检测并清理（2026-09 照片异步复制）；
  - 后台 lambda 只做纯 IO，UI 更新一律回主线程。

## 持久化与迁移

- `schema_version` 与 `DbVersion::kCurrentSchemaVersion`（当前 4）一致；迁移链只追加
  （1→2→3→4），历史迁移函数不得被改写。
- `loadFromFile` 先迁移再解析；迁移后数据与直接保存新版一致（自检覆盖）。
- v4 迁移：`migrateV3ToV4` 递归为每个节点 info 补 `native_regions=[]`、`habitat=""`，
  保证与“直接按 v4 保存”一致。
- 默认数据目录为 exe 同级 `bin/data/`，支持 `--data-dir`；代码无写死的源码绝对路径。
- JSON 往返无损；旧字段缺失时有安全默认值。
- 导出副本（exportCopy）：数据库与照片一起打包到目标目录，导出后副本可独立加载。

## 验证手段

- 静态：用 `rg -n` 查找 double 直接 `==`、未接滚轮过滤器的下拉控件、月份/范围格式化逻辑、toJson 与 fromJson 字段不配对、硬编码路径、绕过 `PhotoImageUtils::loadScaled` 直接 `QPixmap(path)` 全量解码大图等。
- 结构可维护性（发布前建议一并看）：`mainwindow.cpp` 是否持续膨胀（撤销重做/收藏夹/
  复制/导出/导入/高级检索都堆在主窗口）；`docs/ARCHITECTURE.md` 是否与当前实现脱节
  （等级链、schema 版本、模块清单）；新增模块是否职责单一。
