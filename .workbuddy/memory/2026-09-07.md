## 同日：为 100 种植物各下载一张照片

来源首选 PPBC 中国植物图像库（国内权威植物图库），兜底为 Bing 图片。
脚本两段：build/tmp_henan/fetch_photos.py（PPBC 自动）+ fetch_photos_fallback.py（PPBC 指定 cid + Bing）。

接口探测要点：
- 直连 Wikimedia 会被墙（ssl 超时），下载需用 http 而非 https（403 vs 200）。
- PPBC autoload：抓首页 Scripts/autoajax.js 找 /ashx/autocomplete.ashx?参数。
- 图片列表：物种页 Scripts/indexsp.js 里 /ashx/getspphotolist.ashx?cid=。
- 尺寸：path /image2/{size}/{hash}.jpg，size=i=75px 缩略，155=235px，b=700px 大图。

匹配优先级：精确 > 中文名一致（含异名） > 同属兜底。下载过滤 <400px/4KB。
白皮松（PPBC 主条目无图）从 Bing 取 700px+ 缩略图。

结果：100/100 物种均有一张照片，bin/data/photos 19MB。匹配质量：
PPBC 精确 81 + 中文名一致 11 + 同属兜底 4 + 手工指定 3（国槐/山药/二球悬铃木）+ Bing 1（白皮松）。

校验：核心层 TaxonomyDocument::loadFromFile 通过（265 节点 / 100 资料）；
PIL 灰度方差全部 >8，无白屏/占位图。

注意事项：PPBC 图片有版权（平台同时卖图），仅供个人本地 app 演示用，
若公开发布请走 PPBC 的购买/授权流程。
