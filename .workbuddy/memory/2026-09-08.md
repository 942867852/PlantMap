  与 `habitat`（生境描述）两个字段——即 A1 地图功能的数据字段。数据模型/序列化/界面
  在之前的 A1 开发中已就位，本次只补「迁移」这一环。
- **迁移**：`dbversion.cpp` 新增 `migrateV3ToV4`（把 schema_version 置 4，并递归给每个节点

  `kCurrentSchemaVersion` 3→4；`migrateToLatest()` 接入 version==3 分支。

  合法 v4 可加载、物种资料/拉丁名保留），并把链式迁移断言从 `==3` 改为 `==4`，
  层级校验用例的 schema_version 改用 `kCurrentSchemaVersion`。**69 项全过**。
- **兼容性结论**：旧库（v3 及更早）完全兼容，`loadFromFile` 先迁移再解析，磁盘文件
  不会被自动改写，用户保存时才落盘为 v4。已用新 core 层实测加载 bin/data/plantmap.json

### 2. 拆分 mainwindow.cpp（1888行 → 约 1500 行）
- `SpeciesEditDialog` → 独立 `specieseditdialog.h/.cpp`（原匿名命名空间类）

  loadFavorites/saveFavorites 等旧方法。
- CMakeLists.txt 新增 3 组 .cpp/.h。编译通过，无 error/warning。

### 3. 修复的 bug
- **Bug：取消编辑后草稿残留**。SpeciesEditDialog::reject() 只 rollback + 删 session 照片，
  未清除草稿文件，导致下次打开同一植物再次弹"发现未保存草稿"。修复：SpeciesForm 新增
  public 方法 `discardDraft()`（复用 clearDraft），reject() 末尾调用它。
- **健壮性**：favoritesstore.h 补 `<QList>` include（之前靠间接包含）。

### 审查确认"非 bug"项
- cloneSubtree 副本共享原件照片文件名：删除原件时 collectAllReferencedPhotos 会保护副本
  仍引用的文件，不会误删，属合理设计（副本共享照片资源）。
- saveDraft 定时器 + showNode 切换：编辑窗口是模态的，编辑期间无法切换节点，无污染风险。
